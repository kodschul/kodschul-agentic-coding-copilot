# Lab 5.1 – Übung: Skill für eine Fremdaufgabe schreiben

**Ändert die FocusList-Projektbasis?** Nein — generische Übung mit einer neuen, projektunabhängigen Aufgabe.

## Ausgangslage

Ein kleines Fremdprojekt mit einer bestehenden REST-API-Struktur (`sample-api/`).

## Aufgaben

1. Definiere den wiederkehrenden Ablauf "REST-Endpoint nach Schema anlegen" in vier bis fünf konkreten Schritten (z. B. Schema → Route → Validierung → Test).
2. Schreibe diesen Ablauf als `SKILL.md` mit klarem Namen, Anwendungsfall und den nummerierten Schritten.
3. Lass Copilot mit dieser Skill einen ersten Endpoint (`GET /widgets`) anlegen.
4. Lass Copilot mit derselben Skill einen zweiten, andersartigen Endpoint (`POST /orders`) anlegen und vergleiche die Struktur beider Ergebnisse.

## Checkpoint

- `SKILL.md` enthält nummerierte, konkrete Schritte (kein allgemeiner Fließtext).
- Beide Endpoints (Aufgabe 3 und 4) folgen sichtbar derselben Struktur (gleiche Schrittreihenfolge, gleiche Dateiaufteilung).

## Abschlusskriterien

- Ein Vergleich beider Endpoints liegt vor, der die strukturelle Übereinstimmung konkret benennt.

## Fallback

Falls keine REST-API-Vorlage zur Hand ist: dieselbe Übung mit einer einfacheren wiederkehrenden Aufgabe durchführen (z. B. "neue CLI-Unterbefehl anlegen") und dieselben vier Schritte sinngemäß anwenden.

# Lab 6.1 – Lösung

## Aufgabe 1: `explain-selection.prompt.md`

```markdown
---
description: Erklärt die aktuelle Selektion kurz und benennt einen Risikofall.
---

Erkläre die aktuell markierte Codeselektion in maximal 3 Sätzen.
Benenne dabei mindestens einen konkreten Risikofall oder Grenzfall,
den die Selektion nicht abzudecken scheint.
```

## Aufgabe 2: Vergleich zweier Aufrufe

Beide Antworten halten die 3-Satz-Grenze ein und enthalten jeweils einen konkreten Risikofall (z. B. bei einer Sortierfunktion: "keine Behandlung von `null`-Werten"), unterscheiden sich aber inhaltlich passend zum jeweiligen Code — die Struktur bleibt konstant, der Inhalt variiert korrekt.

## Aufgabe 3: Erweiterte Variante

```markdown
---
description: Erklärt die Selektion, benennt einen Risikofall und schlägt eine Verbesserung vor.
---

Erkläre die aktuell markierte Codeselektion in maximal 3 Sätzen, benenne
einen Risikofall und schlage danach eine konkrete Verbesserung in einem
weiteren Satz vor.
```

## Aufgabe 4: Einschätzung

Die kurze Variante eignet sich für schnelles Verständnis beim Lesen fremden Codes; die erweiterte Variante eignet sich besser für Review-Situationen, in denen direkt ein nächster Schritt gebraucht wird.

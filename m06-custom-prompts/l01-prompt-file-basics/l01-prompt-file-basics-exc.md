# Lab 6.1 – Übung: Ersten eigenen Prompt schreiben

**Ändert die FocusList-Projektbasis?** Nein — generische Übung an einem Fremdprojekt.

## Ausgangslage

`sample-project/` (bekannt aus Modul 2).

## Aufgaben

1. Schreibe `.github/prompts/explain-selection.prompt.md`, der eine markierte Codeselektion in maximal 3 Sätzen erklärt und mindestens einen Risikofall benennt.
2. Rufe den Prompt auf zwei unterschiedlichen Codeabschnitten auf und vergleiche die strukturelle Form beider Antworten (Satzanzahl, Risikofall vorhanden?).
3. Ergänze eine zweite Prompt-Variante, die zusätzlich einen konkreten Verbesserungsvorschlag verlangt, und rufe sie auf demselben Codeabschnitt wie in Aufgabe 2 auf.
4. Vergleiche beide Prompt-Varianten (Aufgabe 1 vs. 3) hinsichtlich Nutzen und Länge der Antwort.

## Checkpoint

- Beide Antworten aus Aufgabe 2 halten sich strukturell an die Vorgabe (max. 3 Sätze, mindestens ein Risikofall).
- Die Variante aus Aufgabe 3 liefert zusätzlich einen konkreten Verbesserungsvorschlag.

## Abschlusskriterien

- Eine schriftliche Einschätzung liegt vor, welche Prompt-Variante für welchen Einsatzzweck (schnelle Erklärung vs. Review-Vorschlag) geeigneter ist.

## Fallback

Falls die Prompt-Palette in der Umgebung nicht verfügbar ist: den Prompt-Text händisch in den Chat einfügen und das Ergebnis trotzdem gegen die Struktur-Vorgabe prüfen.

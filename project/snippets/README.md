# Snippets für Lab 1.1

Drei KI-generierte Vorschläge zu kleinen, abgeschlossenen Aufgaben. Jeder läuft, jeder hat mindestens eine Schwachstelle. Jedes Snippet liegt in TypeScript und Python vor; inhaltlich sind beide Fassungen gleich.

| Datei | Aufgabe, für die das Snippet generiert wurde |
| --- | --- |
| `snippet-1-upload.ts` / `.py` | Hochgeladene Datei prüfen, bevor sie gespeichert wird |
| `snippet-2-price.ts` / `.py` | Gesamtpreis eines Warenkorbs inklusive Rabatt berechnen |
| `snippet-3-auth.ts` / `.py` | Prüfen, ob eine Person ein Dokument löschen darf |

# MCP-Szenarien für Modul 8

Fünf Situationen aus dem Projektalltag. Für jede ist zu entscheiden, ob ein MCP-Server sinnvoll ist oder die eingebauten Werkzeuge des Agent-Modus (Dateien lesen und bearbeiten, Workspace-Suche, Terminal) reichen, und welches Risiko eine Anbindung mit sich bringt.

| Nr. | Szenario |
| --- | --- |
| 1 | Die Anforderungen für neue FocusList-Funktionen liegen als Markdown-Tickets im Ordner `focuslist-tickets/` neben dem Projektordner. Der Agent soll das passende Ticket finden und daraus eine Aufgabe ableiten. |
| 2 | In `src/actions/complete-task.ts` (bzw. `focuslist/actions/complete_task.py`) soll eine Variable umbenannt und alle Verwendungen im Projekt angepasst werden. |
| 3 | Offene Issues im Git-Hosting des Teams sollen abgefragt, nach Label gefiltert und nach dem Merge automatisch geschlossen werden. |
| 4 | Nach jeder Änderung sollen die Tests des Projekts laufen und der Agent soll das Ergebnis lesen. |
| 5 | Für eine neue Auswertung braucht der Agent das Tabellenschema einer PostgreSQL-Datenbank, die auf demselben Server auch Produktivdaten enthält. |

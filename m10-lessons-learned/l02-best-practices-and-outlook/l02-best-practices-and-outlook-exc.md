# Lab 10.2 – Übung: Best Practices auf ein neues Projekt anwenden

**Ändert die FocusList-Projektbasis?** Nein — Transferübung auf ein fiktives, neues Projekt.

## Ausgangslage

Eine kurze Beschreibung eines neuen, fiktiven Projekts (`neues-projekt-brief.md`, z. B. eine kleine Wetter-Dashboard-App).

## Aufgaben

1. Wähle drei der sechs im Theorieteil genannten Best-Practice-Punkte aus, die für das neue Projekt am wichtigsten wären.
2. Begründe für jeden gewählten Punkt konkret, welches Problem er im neuen Projekt verhindern würde.
3. Formuliere für einen der drei Punkte eine konkrete erste Maßnahme (z. B. einen Entwurf für die erste `copilot-instructions.md`-Regel).
4. Identifiziere einen Punkt, der für das neue Projekt eher NICHT priorisiert werden sollte, und begründe warum.

## Checkpoint

- Drei gewählte Punkte sind konkret auf das neue Projekt bezogen begründet (nicht nur wiederholt).
- Eine konkrete erste Maßnahme aus Aufgabe 3 liegt schriftlich vor.

## Abschlusskriterien

- Eine begründete Entscheidungsnotiz liegt vor, welche drei Best Practices zuerst eingeführt würden und welche (vorerst) nicht.

## Fallback

Falls kein Projektbrief vorliegt: das eigene FocusList-Projekt aus Sicht "Was würde ich beim nächsten Mal von Anfang an anders/früher einführen?" reflektieren.

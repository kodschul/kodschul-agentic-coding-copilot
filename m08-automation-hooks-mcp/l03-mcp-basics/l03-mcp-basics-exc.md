# Lab 8.3 – Übung: MCP-Konzept an einem Beispiel einordnen

**Ändert die FocusList-Projektbasis?** Nein — konzeptuelle Übung, keine Codeänderung.

## Ausgangslage

Eine kurze Liste von fünf Beispielszenarien (`mcp-scenarios.md`), von denen einige für MCP geeignet sind und andere nicht.

## Aufgaben

1. Ordne jedes der fünf Szenarien einer der beiden Kategorien "MCP sinnvoll" oder "eingebautes Tool reicht" zu.
2. Begründe für jede Zuordnung in einem Satz, warum.
3. Wähle das für FocusList relevanteste Szenario (externe Notizen/Tickets) aus und beschreibe, welche konkreten MCP-Tools ein passender Server dafür anbieten müsste (z. B. "Tickets nach Stichwort suchen").
4. Diskutiere zu zweit: Welches Risiko entsteht, wenn ein MCP-Server zu weitreichende Zugriffsrechte bekommt?

## Checkpoint

- Alle fünf Szenarien sind mit Begründung zugeordnet.
- Für das FocusList-Szenario liegt eine konkrete Liste möglicher Tool-Namen vor.

## Abschlusskriterien

- Eine schriftliche Risikobetrachtung aus Aufgabe 4 liegt vor.

## Fallback

Falls unklar, wie ein Szenario einzuordnen ist: die Frage "Bräuchte das Modell Zugriff auf ein System außerhalb dieses Projekts?" als Entscheidungshilfe nutzen.

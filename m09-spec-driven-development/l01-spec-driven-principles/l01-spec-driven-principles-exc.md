# Lab 9.1 – Übung: Erste Spec für ein Fremdbeispiel

**Ändert die FocusList-Projektbasis?** Nein — generische Übung an einem neuen Beispiel-Feature.

## Ausgangslage

Beispiel-Feature-Idee: "Nutzer können Kommentare zu einem Blogpost hinzufügen" (Fremdprojekt, unabhängig von FocusList).

## Aufgaben

1. Schreibe ein kurzes Proposal (2-3 Sätze: Problem, Ziel) für das Kommentar-Feature.
2. Schreibe eine Spec mit konkreten Anforderungen (Datenmodell, mindestens zwei Randfälle, z. B. leerer Kommentar, sehr langer Kommentar).
3. Lass anhand der Spec eine erste Implementierung generieren.
4. Prüfe, ob die generierte Implementierung tatsächlich beide in der Spec benannten Randfälle behandelt.

## Checkpoint

- Proposal und Spec liegen als zwei getrennte, kurze Dokumente vor.
- Mindestens zwei konkrete Randfälle sind in der Spec benannt.

## Abschlusskriterien

- Die generierte Implementierung behandelt beide benannten Randfälle nachweislich (Test oder manuelle Prüfung).

## Fallback

Falls die generierte Implementierung einen Randfall nicht behandelt: die Spec um eine präzisere Formulierung ergänzen und die Implementierung erneut generieren lassen, statt den Randfall einfach zu ignorieren.
